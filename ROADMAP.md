# Orchestra roadmap

Orchestra is progressing toward a durable, reproducible multi-agent system for
real software projects.

## v0.2.0 — Native Multi-Agent Execution

- NativeRuntime activation — closed
- Native worker pool — implemented
- Planner and task graph
- Shared project context
- Reviewer and judge
- Recovery loop
- Model router
- Multi-agent Console

## v0.3.0 — Durable Project Intelligence

- Context intelligence
- Artifact management
- Structured project memory
- Improved scheduling

## v0.4.0 — Autonomy and Advanced Workflows

- Hierarchical planning
- Dynamic specialization
- Advanced review and judge workflows
- Long-running autonomous objectives
- Budgets and bounded autonomy
- Human escalation

## v0.5.0 — Hardening and Beta

- Secret management and threat-model hardening
- Runtime permissions and quotas
- Backup, restore, upgrades, and rollback
- Crash and chaos recovery
- Observability
- SDK, provider, and runtime extension surfaces

## v1.0

Orchestra can receive a complex software project, decompose it, coordinate
multiple agents over long-running work, survive failures and restarts,
review and correct results, enforce execution boundaries, and produce durable,
reproducible project state suitable for real use.
